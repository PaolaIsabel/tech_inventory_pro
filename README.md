# Tech Inventory Pro

Aplicación desarrollada en Flutter para la gestión de inventario de activos tecnológicos, permitiendo registrar computadoras, impresoras y otros equipos.

<!-- BADGE_CI -->

## Instalación local 🚀

```bash
git clone https://github.com/PaolaIsabel/tech_inventory_pro.git
cd tech_inventory_pro
flutter pub get
flutter run
```

## Variables de configuración

Este proyecto no utiliza actualmente un archivo `.env`.

## Comandos disponibles

| Comando | Descripción |
|----------|-------------|
| `flutter pub get` | Instala las dependencias |
| `flutter run` | Ejecuta la aplicación |
| `flutter build apk` | Genera el APK |
| `flutter test` | Ejecuta las pruebas (pendiente) |

## Tecnologías

- Flutter
- Dart
- Material Design
